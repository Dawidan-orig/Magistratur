front-end templates (Нейро):
HTML-шаблоны (Jinja2-подобный синтаксис) в `templates/app_name/`. Рендерят данные из views через `{{ variable }}`, `{% for %}`, `{% form.as_p %}`

У слоя serializers три основные функции (все выводы для serializers справедливы и для forms):
- валидировать данные
- преобразовывать данные запроса в типы данных Python
- преобразовывать сложные Python объекты в простые типы данных Python (например, Django модели в dict)

View и Model не сильно отличается от классического MVC.
#### **Слой Views**
Слой View в контексте Django отвечает за представление и обработку пользовательских данных, в нем мы описываем, какие данные нам нужны и как мы хотим их представить

## **Слой models**
Если опираться на более продвинутые туториалы или вспомнить слой Model в MVC, то кажется, что models отличное место для размещения бизнес-логики.

Mercurial:
Распределенная система контроля версий разрабатывалась параллельно с системой контроля версий Git.
Первоначально, она была создана для эффективного управления большими проектами под Linux’ом

### Git
#### Commit
коммит это основной объект в любой системе управления версиями.
коммиты это односвязный список, состоящий из объектов в которых содержаться измененные файлы, и ссылка на предыдущий коммит.
#### Fork
Это создание полной копии репозитория (Вообще, GitHub-GitLab)
#### Merge
Контекст веток.
Каждое слияние двух и более коммитов в один — это merge (объединение двух и более наборов изменений).   
Каждое разветвление — это появление нескольких вариантов изменений.

Checkout. Add. Commit. Push. Pull. Fetch. Merge. Ветки и переходы.

Это набор команд для навигации между коммитами, ветками и состояниями репозитория (checkout, switch, reset), позволяющие безопасно переключаться без потери изменений.

#### Команды жизненного цикла

- git clone {url} — скачивает репозиторий с удаленного сервера локально с историей.
- git add {file} — добавляет изменения в индекс (staging area) для коммита.
- git commit -m "msg" — фиксирует индекс в историю как новый снимок.
- git push — отправляет локальные коммиты в удаленный репозиторий.
- git pull — fetch + merge с remote (git fetch + git merge).

#### Синхронизация и слияние
- **git fetch** — загружает изменения с remote без слияния в локальные ветки.
- **git merge {branch}** — сливает указанную ветку в текущую (создает merge-коммит)
#### Ветки и переходы
- **git checkout {branch}** — переключается на ветку (или коммит); `git checkout -b new` — создает и переходит.
- **git branch** — список веток; `git branch new` — создать; `git branch -d old` — удалить.

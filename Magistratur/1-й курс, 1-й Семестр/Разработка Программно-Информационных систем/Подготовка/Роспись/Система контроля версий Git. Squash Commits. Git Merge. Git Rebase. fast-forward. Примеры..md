#### Squash Commits
это техника объединения нескольких последовательных коммитов в один для упрощения и очистки истории проекта

#### Git Merge
Сливает ветку в основную, создавая merge-коммит (если есть расхождения)

#### Git Rebase

"Переписывает" историю: перемещает коммиты feature поверх main линейно. Затем делает merge без коммита.
main A---B, feature A---C---D
→ feature A---B---C'---D'

#### Fast-Forward
Применяется, когда нет конфликтов.
Автоматическое линейное слияние без merge-коммита, если ветка не разошлась. `git merge --ff-only`. Пример: main ...A---B, feature ...A---B---C → main ...A---B---C (просто сдвиг указателя).

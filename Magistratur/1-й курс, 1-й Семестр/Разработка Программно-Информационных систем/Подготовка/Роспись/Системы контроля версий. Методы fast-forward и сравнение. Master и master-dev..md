Метод **fast-forward** в Git — это автоматическое линейное слияние веток без создания merge-коммита, когда история **main** является префиксом истории **feature**

Fast-forward происходит, если с момента создания feature ветка main не изменилась.

```
main:     A --- B
             \
feature:      C --- D → git merge feature → A - B - C - D (main)

```

#### Master и master-dev
- **master/main** — стабильная ветка (production-ready код).
- **master-dev/develop** — ветка разработки (интеграция feature веток).

 feature → dev → main. Fast-forward используется для dev→main, `--no-ff` для явного merge

Нейро:
Domain-модель — это объектная репрезентация предметной области (домена) в коде, включающая сущности, их свойства, поведение и бизнес-правила.
​
Элементы:
- **Сущности (Entities):** Объекты с уникальным ID и жизненным циклом (Order, Customer).
- **Объекты-значения (Value Objects):** Неизменяемые структуры без ID (Address, Money).

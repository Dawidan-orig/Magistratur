## Совместное использование файлов
- **Locking (блокировка):** Один редактирует файл за раз (CVS, старые SVN) — избегает конфликтов, но замедляет параллельную работу.
- **Merge-based (слияние):** Все редактируют параллельно, конфликты разрешаются вручную (Git, Mercurial) — быстрее для команд.
## Хранение изменений
- **Полные снимки (Snapshots):** Каждая версия — независимый снимок всего репозитория (Git).
- **Дельта-хранение (Delta):** Только разности между версиями (SVN, RCS) — экономит место для текстовых файлов, хуже для бинарных.
